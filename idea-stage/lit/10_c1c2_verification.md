## 2. C2（多语言剪枝税）——用已发表表格检验

数据：`c2_published_en_cn_tax.csv`。定义 tax =（CN 掉分）−（EN 掉分），单位为分；正数表示中文吃亏更多。

**按"是否按问题选 token"分组的平均 tax：**

| 来源（同一套实验代码） | 模型 | 保留 token | 按问题选 (Y) | 不看问题 (N) |
|---|---|---|---|---|
| CDPruner Tab.1 | LLaVA-1.5-7B | 128 | +1.1 | −1.3 |
| CDPruner Tab.1 | LLaVA-1.5-7B | 64 | +3.1 | −0.2 |
| CDPruner Tab.1 | LLaVA-1.5-7B | 32 | +7.2（TRIM 11.0、CDPruner 3.4） | +1.6 |
| CDPruner Tab.3 | **Qwen2.5-VL-7B** | 512 / 256 / 128 | +0.3 / +1.2 / +0.6 | −0.1 / +0.8 / +0.4 |
| DART Tab.1 | LLaVA-1.5-7B | 192 / 128 / 64 | 0.0 / −1.7 / −7.4 | +0.5 / +0.1 / +0.9 |

**结论：**
1. **Qwen2.5-VL-7B 上中文税基本为 0**（≤1.4 分，在 MMBench 的统计噪声内），按问题选与不看问题之间差 ≤0.8 分。以中文为主线的 C2 在现代双语模型上不成立。
2. LLaVA-1.5 上，在 CDPruner 这套统一实验里，按问题选的方法在激进剪枝时中文多掉 3–7 分。但最大的一项来自 **TRIM，它用 CLIP 的英文文本编码器给 token 打分**，看不懂中文是显然的，这属于平凡解释，不是新发现。
3. **同一方法、同一模型、同一预算，两篇论文的数字差异比效应本身还大**：FastV / LLaVA-1.5 / 128 token，DART 表是 EN 56.1 / CN 56.4（tax −6.9），CDPruner 表是 EN 63.0 / CN 55.9（tax +0.5）。PDrop 在 DART 表 64 token 下英文掉到 33.3，明显是格式/实现问题。说明从已发表表格无法建立 C2，只能自己统一实验。
4. 机制层面的可信支撑只有 **CLAIM（ACL'25 Main）**：非英文提问时，LLaVA-1.5 和 Qwen-VL-Chat 对相关图像区域的注意力下降约 32%。但这是 2023 年代的模型，且 CLAIM 已经提出了跨语言注意力干预（是 C2 修复方法的直接竞争者）。
5. 剩下唯一没被否定的空间是**低资源语言**（孟加拉语、斯瓦希里语等），但没有任何顶会证据；且低资源语言下完整模型本身准确率就低，地板效应会让 tax 很难测准。

**C2 判定：在中文和现代模型上基本已被现有数据否定；低资源语言版本无证据、风险高。不建议作为主线。**

## 3. C1（同义改写不稳定）——顶会证据

没有任何论文直接测过"同义改写下保留集的变化"，所以无法从表格检验，只能看机制证据：

1. **FEATHER（ICCV'25）是对 C1 最直接的威胁**：FastV 式在浅层（K=3）用注意力选 token 时，选中的 token 集中在图像底部——保留 25% 时，选中 token 的平均位置在图像从上往下 80.7% 处（卡方检验显著）；只有在更深的层（K=8/16/24）位置偏差才减弱，选择才开始和问题相关。
   含义：FastV 默认在第 2 层剪枝，**选择主要由位置决定而不是由问题决定**，那么换个说法问，保留集大概率几乎不变（Jaccard 高）。C1 在 FastV 默认设置下很可能是零结果。
2. C1 可能成立的地方是**真正用文本相关性打分的方法**（SparseVLM、TRIM、CDPruner、深层剪枝的 FastV/PDrop）。但这些方法的"不稳定"可能又被位置偏差或文本编码器能力（TRIM 的 CLIP 英文编码器）这类平凡原因解释。
3. "提示措辞会改变 LLM 行为"本身是顶会公认现象（Sclar et al., ICLR'24），但它说的是输出层面；"MLLMs Know Where to Look"（ICLR'25）反而表明 MLLM 中深层注意力能稳定地定位到问题相关区域，这也暗示深层选择可能对改写较稳定。

**C1 判定：文献里没有正面证据，FEATHER 的结果预示 FastV 默认设置下会是零结果；对文本相关性类方法是开放问题，必须靠 pilot 判定。**

## 4. 可行性小结

| | 空间 | 证据 | 可行性 |
|---|---|---|---|
| C1 | 没人做过（查新成立） | 无正面证据；FEATHER 预示 FastV 下可能为零 | 很便宜：算保留集只需跑模型前几层，CPU 也能做 |
| C2 | 中文版已被数据否定；低资源语言版没人做 | 只有 CLAIM（老模型）支持机制；现代模型表格为零效应 | 测量难：低资源语言地板效应 + 实现噪声 |

**建议：先用 CPU 跑 C1 的最小 pilot（只算保留集，不生成答案），一并测几种低资源语言的保留集变化。如果 Qwen2.5-VL 上改写/换语言后的保留集 Jaccard 都 ≥0.8，C1 和 C2 都应放弃。**
