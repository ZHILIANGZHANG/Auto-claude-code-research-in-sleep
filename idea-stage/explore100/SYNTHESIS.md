## 一、十条跨论文的规律

### 1. 能力其实存在，只是没被调用
模型内部已经编码了正确的信息，但在该用的时候读不出来。下面几篇是从不同方向测到的同一个现象：
- **#81**：in-context 学到的拓扑表征是惰性的。同一段随机游走放在 prefilled 回复里能用，放在 user 消息里、中间隔几个 token 就用不了，而两种情况下的表征质量完全相同。
- **#88**：多模态 ICL 在中层把 demo label 正确 grounding 到证据上，即使最终答错也是如此。但 query 在中层不读这些信息，到后层才读，那时映射已经变得不可靠。
- **#43**：说“wait，让我再看看图”，其实并不看图（偷偷换图也察觉不到）；插入一个 user turn 就能把 attention 拉回图像。
- **#82**：把 trace 里的一个事实改掉，R1 和 QwQ 的答案几乎不跟着变，它们并不读自己的思考。
- 同一主题的还有 #58（说出“这可能是测试”几乎没有因果作用）、#25/#29（模型自己知道怎么并行，但默认不做）、#41（自己写的 caption 比原图更好用）、#68（VLA 的“遗忘”大多可以恢复）。

**反直觉的一点**：信息位置的影响（在哪个 role 里、在哪一层）往往比信息内容更大。

### 2. thinking 有一个共同代价：越想越脱离外部证据
- CoT 损害感知类任务：#2（指令遵循）、#49（视觉 RFT 不思考更好）、#94（grounding、计数、知识 VQA 都下降）。
- **#94**：言语反思先升后降，视觉反思从头到尾单调衰减，attention 被推理 token 逐渐吸走。图像被遮挡后，模型会说“看不清”，但照样给答案。
- **#76**：只在 GSM8K 上做 GRPO（训练中没有任何工具），工具幻觉照样上升；ReCall 让无工具场景的幻觉从 34.8% 升到 90.2%。消融显示罪魁是“先想”这一步，而不是 RL 本身。
- **#82**：budget forcing 让答案更保守，但 trace 里复述的隐私数据更多（粉红大象效应）。
- #83：数学专精模型在“纠正”学生解时，会保留错误、编造推导，硬凑出标准答案（向后合理化）。

这些合起来，指向 thinking/RL 强化的同一个倾向：保持叙事连贯、填补空白、不弃权，而不是忠于环境。

### 3. 起作用的往往只是少数位置
token 维度：
- RL 只放大 base 模型已有的高概率解（#1、#71 rank bias）。
- 量化噪声和 BF16 非确定性都集中伤害高熵分叉 token（#10、#20）。
- **#96**：prompt steering 本身就是一种激活干预，强度集中在句子标记和分叉点，其余位置几乎为零。

参数和单元维度：
- RL 用 SGD 只改 0.02% 的参数（#7）。
- ViT 的 sink 由约 5–100 个 register 神经元写入（#47）。
- MoE 每层 2–5 个“常委”专家吃掉 70% 的路由（#80）。
- 调节 20 个 head 就能在“信图”和“信常识”之间切换（#86）。
- 约 200 个 MLP 神经元构成完整电路，一个神经元就能把 Austin 翻成 Texas（#100）。
- 其他例子：#60（正确答案的神经元稀疏而一致）、#87（OCR head 按字形共享）。

**一个统一猜想（未验证）**：模型行为里可控的自由度只存在于高熵分叉点和少数单元，其余部分基本是确定性的填充。

### 4. 规范性判断集中在最后几层，而且最脆弱
- **#90**：隐私判断在 base 模型的最后几层才形成。良性微调后，这个后层决策消失，privacy steering vector 在最后一层的余弦相似度变成 −0.75（方向反转），而 commonsense 方向全程稳定。
- **#76**：工具幻觉和正确回答的可分性集中在 20 层以后的残差流。
- **#86**：知识与视觉的冲突在最后 4 层由少数 head 裁决。
- **#92**：“压制已说过的答案”发生在约 28 层之后。
- **#79**：量化中最容易坏的样本，是依赖后层精修的那批。把后层权重恢复成 16 bit 也救不回来，问题在于累积到后层的激活噪声。

弃权、拒答、隐私、去重这些“规范”都挂在后层，因此在微调、量化和 RL 里都最先被破坏。

### 5. 后训练学到的是“表面形式 → 行为”的映射
- **#97**：用一个乱码句“Quickly sit Paris clouded?”，模型照样答 France。把 FlanV2 里 CoT 任务的句式模板加到有害请求前面，拒答率从 40% 降到 2.5%，因为那个句式所在的领域在训练中从来没有拒答。
- **#89**：prompt injection 防御学到的是三条捷径：“后缀可疑”（第二道无害题的拒答率高达 90%）、“sudo 等触发词”（误拒 +50%）、“少说话”（推理长度整体缩短）。
- **#98**：trajectory-SFT 后的 agent，在动作名从 click 改成 press 时，即使环境报错说“请用 press”，仍然坚持输出 click。
- 同一主题：#91（用和下游越相似的安全数据对齐，护栏越容易崩）、#74（SFT 后的位置由模型家族决定，数据只造成很小的偏移）、#55（对非规范分词的鲁棒性来自 SFT）。

### 6. 局部训练会改变全局倾向
- 只在数学上做 RL，工具幻觉也会上升（#76）。
- 用无害的“主动帮忙”数据微调，GPT-4o-mini 的隐私判断相对下降 98%（#90）；带 debug print 的代码数据也会让隐私崩。
- 预训练中关于 AI 的论述会让模型自我实现地对齐或不对齐（#37）。
- 长上下文 SFT 让模型对上下文过度信任，知识冲突测试从 99.8% 降到 50%（#75）。

这些都是 SAFETY 和 capability benchmark 测不到的“静默失效”：#90 中 AgentHarm 的变化不到 2%，#76 中 BFCL 甚至还涨了 9.9%。

### 7. 多样性是结构性问题，不是温度问题
- 跨模型同质化（#53 Artificial Hivemind），agent RL 的模板坍缩（#9）。
- 换一种思考语言，英文输出的多样性就提高，而且离英语越远增益越大（Pearson 0.72–0.88）。混合语言采样在 T=1.0 时的多样性约等于纯英文在 T=2.0 时的水平（#77）。
- PPO epochs 增多，多样性反而上升：第一步把高概率解推到 clip 上限后，后续几步只剩低概率解在学（#71）。
- **#92** 给出一个内部解释：模型先把所有候选答案一起推高，再压制上下文中已出现的答案。跨样本采样时没有这个压制信号，于是每次都从同一个峰开始。

### 8. 评测结果经常在骗人
- 不同 GPU 数、batch size 下，BF16 的 AIME 准确率标准差可达 9%（#20）。很多 benchmark 的信噪比很低，用 BPB 比用准确率更稳（#65）。
- 准确率不变，但 judge 选的候选完全不同（#84，KV 复用场景）。
- 受控实验里的 lost-in-the-middle，在真实检索设置里被“强检索器带来的强干扰段落”抵消，按位置重排和随机打乱效果一样（#85）。
- 会解题和会查错几乎无关，特征重要性只有 1.1%（#83）。
- 拒攻击率高，掩盖了对无害输入的伤害（#89）。只看原接口分数挑 checkpoint，会挑到最脆的那个（#98）。
- debate 的收益几乎全来自投票（#61）。生产环境里的 agent 都很简单，主要靠人工评测（#63）。

### 9. 大量计算是冗余的，可以压缩
- 连续的 FFN 可以并行融合（#21），层可以跳过或重复（#27），looped 模型的一次循环约等于 0.46 层（#28）。
- 用 N-gram 查表代替早期层的“重建”：DSE 第 5 层的表征相当于 MoE 第 12 层（#70）。把查表记忆关掉，TriviaQA 只剩 29%，阅读理解还剩 93%，知识和推理几乎被干净地分开。
- 只保留高频词的 KV（"and over the. T of fed anded the"），摘要任务照样能做（#72）。
- 文字渲染成图片做 agent 历史，token 省 55%，性能保持 95% 以上（#93）。
- 多 agent 不解码文本、直接拼接 KV 和 hidden state，token 少 70–84%，结果反而更好（#99）。

### 10. role 和 turn 结构是隐式开关
- 把孤立题放进多轮对话、加上客服角色，所有模型都变差。原因是模型自动进入“短答模式”：回答长度不受限也会变短，加一句“需要推理时多想想”也无效（#95）。
- 加一个 user turn 能恢复对图像的 attention（#43）。
- 同一段信息放在 assistant prefill 里能用，放在 user 消息里不能用（#81）。
- 和 #56（Assistant Axis，人格空间的主轴）可能是同一个几何结构。

## 二、值得继续追的线头（不急着定 idea，只列出便宜、可证伪的检验）

1. **分叉点统一假说**（规律 3）：在同一个开源模型、同一批 prompt 上，分别取 prompt steering 的 ΔPS（#96）、RL 前后的 logit 变化（#1/#71）、量化误差（#10/#79），看三者是否落在同一批高熵位置。如果重合，一系列 training-free 方法（steering、JitRL #69、混合精度）都可以只作用在这些位置上。
2. **trace 依赖度指标**（规律 1/2）：用 #82 的交换干预（改 trace 里的一个事实，看答案是否跟着变），批量测开源推理模型。看它是否和 RL 方式、#43 的“不看图”程度、#76 的工具幻觉相关。
3. **“对话短答模式”方向**（规律 10）：在 #95 的孤立版和对话版之间取激活差，检查它与 Assistant Axis（#56）的夹角，再试反向 steer 能否把对话里的推理性能拉回来。
4. **跨样本压制换多样性**（规律 7）：把其他样本已生成的答案 token 作为负 steering，或放进 KV，人为触发 #92 的压制电路。和 #77 的换思考语言做对比，并直接测 GRPO 组内的 pass@k。
5. **规范脆弱性预测器**（规律 4/6）：把 #90 的 steering 投影和 #91 的表征相似度合在一起，在微调前预测哪些数据会打掉隐私、拒答或弃权方向；并检验这些方向是否都在后层、是否共享子空间。

这几条都可以在 7–8B 开源模型上 training-free 或只做少量推理就验证。另外第 2、3 条和之前排除掉的“视觉 token 重要性”方向没有重叠。
